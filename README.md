# Independent Brokers Association

Website for independentbrokersassociation.org: a static HTML/CSS/JS site for a real estate broker membership association.

- Pages: Home, About, Membership (with join form), Events, Resources, Contact
- Shared styling and scripts in `assets/`
- Hosted on Hostinger, deployed from `main` via GitHub

## Notes
- Forms currently open the visitor's email app addressed to `info@independentbrokersassociation.org`. Swap in a form service endpoint in `assets/site.js` when ready.
- Leadership, events, dues and the resource library are placeholders to fill in.
